## Описание

Приложение для решения физических задач по теме «Давление жидкостей и газов».  
Реализовано на **Avalonia UI** (кроссплатформенный аналог WinForms) с использованием языка **C#** и платформы **.NET**.

---

## Задачи

### Задача 1 — Объём цилиндра (архимедова сила)
Цилиндр взвешивают в воздухе и в воде. По разнице показаний вычисляется архимедова сила,
из которой находится объём цилиндра.

**Формула:**  
`F_арх = P_воздух − P_вода`  
`V = F_арх / (ρ × g)` → перевод в см³

### Задача 3 — Гидравлический пресс
По закону Паскаля давление передаётся одинаково во все стороны.
Зная силу на малом поршне и соотношение площадей, находим силу на большом поршне.

**Формула:**  
`F₂ = F₁ × k`, где `k = S₂ / S₁`

## Как работает код

Приложение разделено на два файла по принципу, аналогичному WinForms:

**`MainWindow.axaml`** — описывает внешний вид окна: расположение полей ввода, подписей и кнопок. Это аналог `Form1.Designer.cs` в WinForms. Каждому элементу присваивается имя через `x:Name`, чтобы к нему можно было обратиться из кода.

**`MainWindow.axaml.cs`** — содержит логику расчётов. Здесь два обработчика событий — по одному на каждую кнопку, аналог `button1_Click` в WinForms:

- `CalcVolume_Click` — читает значения из полей ввода (`AirWeight_TB.Text`, `WaterWeight_TB.Text`), проверяет их корректность через `double.TryParse`, вычисляет архимедову силу и объём, затем записывает результат в `Volume_TB.Text`.
- `CalcPress_Click` — аналогично читает `F1_TB.Text` и `K_TB.Text`, перемножает их и выводит результат в `F2_TB.Text`.

Поля с результатами имеют свойство `IsReadOnly="True"` (аналог `ReadOnly = true` в WinForms) — пользователь не может редактировать их вручную. При некорректном вводе в поле `Error_L` выводится сообщение об ошибке красным цветом.
