## 📚 Теоретическая часть

### Что такое ООП?

**Объектно-ориентированное программирование (ООП)** — это парадигма разработки, основанная на определённых правилах и принципах. Весь код состоит из объектов, которые взаимодействуют друг с другом.

### Основные элементы ООП:

| Элемент | Описание | Пример в коде |
|---------|----------|---------------|
| **Класс** | Шаблон, на базе которого создаются объекты | `class Vehicle { ... }` |
| **Объект** | Экземпляр класса с конкретными характеристиками | `Vehicle car = new Vehicle(...)` |
| **Атрибут** | Характеристика объекта (свойство) | `public string Make { get; set; }` |
| **Метод** | Функция внутри класса, определяющая поведение | `public void DisplayInfo()` |

### Основные принципы ООП:

| Принцип | Описание | Реализация в работе |
|---------|----------|---------------------|
| **Инкапсуляция** | Данные и методы для работы с ними хранятся внутри объекта | Все атрибуты и методы находятся внутри классов |
| **Наследование** | Классы могут наследовать свойства и методы друг от друга | `Car : Vehicle`, `Truck : Vehicle` |
| **Полиморфизм** | Один и тот же метод может работать по-разному в разных классах | Метод `DisplayInfo()` переопределён в каждом классе |

## 🚗 Практическая часть

### Тема работы: Транспортные средства

В работе реализована иерархия классов для описания транспортных средств:

```
┌─────────────┐
│ Vehicle │ (базовый класс)
│ (машина) │
└─────────────┘
▲
││
┌─────────────┴┴─────────────┐
│ │
┌───────┴───────┐ ┌───────┴───────┐
│ Car │ │ Truck │
│ (легковой) │ │ (грузовик) │
└───────────────┘ └───────────────┘
```


### Иерархия классов:

#### Базовый класс `Vehicle` (Транспортное средство)
- **Атрибуты:** Марка, Модель, Год выпуска, Стоимость
- **Методы:** DisplayInfo() - вывод информации

#### Производный класс `Car` (Легковой автомобиль) → наследует `Vehicle`
- **Дополнительные атрибуты:** Количество дверей, Тип кузова
- **Переопределённый метод:** DisplayInfo() - выводит всю информацию + специфичную для авто

#### Производный класс `Truck` (Грузовик) → наследует `Vehicle`
- **Дополнительные атрибуты:** Длина кузова, Тяговая мощность
- **Переопределённый метод:** DisplayInfo() - выводит всю информацию + специфичную для грузовика

## 💻 Код программы

### Полный код Program.cs:

```csharp
using System;

// ==========================================================
// БАЗОВЫЙ КЛАСС Vehicle (Транспортное средство)
// ==========================================================
class Vehicle
{
    // АТРИБУТЫ (свойства класса)
    public string Make { get; set; }      // Марка
    public string Model { get; set; }     // Модель
    public int Year { get; set; }         // Год выпуска
    public decimal Price { get; set; }    // Стоимость

    // КОНСТРУКТОР - вызывается при создании объекта
    public Vehicle(string make, string model, int year, decimal price)
    {
        Make = make;
        Model = model;
        Year = year;
        Price = price;
    }

    // МЕТОД для вывода информации
    public virtual void DisplayInfo()
    {
        Console.WriteLine("--- Информация о транспортном средстве ---");
        Console.WriteLine($"Марка: {Make}");
        Console.WriteLine($"Модель: {Model}");
        Console.WriteLine($"Год выпуска: {Year}");
        Console.WriteLine($"Стоимость: {Price} руб.");
        Console.WriteLine("------------------------------------------\n");
    }
}

// ==========================================================
// ПОДКЛАСС Car (Легковой автомобиль)
// ==========================================================
class Car : Vehicle
{
    // ДОПОЛНИТЕЛЬНЫЕ АТРИБУТЫ
    public int NumDoors { get; set; }      // Количество дверей
    public string BodyStyle { get; set; }  // Тип кузова

    // КОНСТРУКТОР - вызывает конструктор родителя через base()
    public Car(string make, string model, int year, decimal price, int numDoors, string bodyStyle) 
        : base(make, model, year, price)
    {
        NumDoors = numDoors;
        BodyStyle = bodyStyle;
    }

    // ПЕРЕОПРЕДЕЛЁННЫЙ МЕТОД
    public override void DisplayInfo()
    {
        Console.WriteLine("========== ЛЕГКОВОЙ АВТОМОБИЛЬ ==========");
        Console.WriteLine($"Марка: {Make}");
        Console.WriteLine($"Модель: {Model}");
        Console.WriteLine($"Год выпуска: {Year}");
        Console.WriteLine($"Стоимость: {Price} руб.");
        Console.WriteLine($"Количество дверей: {NumDoors}");
        Console.WriteLine($"Тип кузова: {BodyStyle}");
        Console.WriteLine("==========================================\n");
    }
}

// ==========================================================
// ПОДКЛАСС Truck (Грузовик)
// ==========================================================
class Truck : Vehicle
{
    // ДОПОЛНИТЕЛЬНЫЕ АТРИБУТЫ
    public string BedLength { get; set; }      // Длина кузова
    public string TowingCapacity { get; set; } // Тяговая мощность

    // КОНСТРУКТОР
    public Truck(string make, string model, int year, decimal price, string bedLength, string towingCapacity) 
        : base(make, model, year, price)
    {
        BedLength = bedLength;
        TowingCapacity = towingCapacity;
    }

    // ПЕРЕОПРЕДЕЛЁННЫЙ МЕТОД
    public override void DisplayInfo()
    {
        Console.WriteLine("============== ГРУЗОВИК ==============");
        Console.WriteLine($"Марка: {Make}");
        Console.WriteLine($"Модель: {Model}");
        Console.WriteLine($"Год выпуска: {Year}");
        Console.WriteLine($"Стоимость: {Price} руб.");
        Console.WriteLine($"Длина кузова: {BedLength}");
        Console.WriteLine($"Тяговая мощность: {TowingCapacity}");
        Console.WriteLine("=======================================\n");
    }
}

// ==========================================================
// ГЛАВНЫЙ КЛАСС ПРОГРАММЫ
// ==========================================================
class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("==========================================");
        Console.WriteLine("ЛАБОРАТОРНАЯ РАБОТА №2: КЛАССЫ И НАСЛЕДОВАНИЕ");
        Console.WriteLine("Тема: Транспортные средства");
        Console.WriteLine("==========================================\n");

        // СОЗДАЁМ ОБЪЕКТЫ
        Console.WriteLine(">>> Создаём объекты:\n");

        Vehicle vehicle = new Vehicle("Toyota", "Corolla", 2022, 1800000);
        Car car = new Car("Toyota", "Camry", 2022, 2900000, 4, "седан");
        Truck truck = new Truck("Ford", "F-MAX", 2023, 6000000, "6162 мм", "13 т");

        // ВЫВОДИМ ИНФОРМАЦИЮ
        Console.WriteLine(">>> Вывод информации о созданных объектах:\n");
        
        vehicle.DisplayInfo();
        car.DisplayInfo();
        truck.DisplayInfo();

        // ДЕМОНСТРАЦИЯ ПОЛИМОРФИЗМА
        Console.WriteLine(">>> Демонстрация полиморфизма:");
        Console.WriteLine(">>> Создаём массив объектов Vehicle и вызываем DisplayInfo():\n");

        Vehicle[] vehicles = { vehicle, car, truck };
        
        for (int i = 0; i < vehicles.Length; i++)
        {
            Console.WriteLine($"Элемент {i + 1}:");
            vehicles[i].DisplayInfo();
        }

        Console.WriteLine("==========================================");
        Console.WriteLine("ПРОГРАММА ЗАВЕРШЕНА");
        Console.WriteLine("==========================================");
    }
}
```

🔍 Анализ передачи данных

Как передаются данные при создании объекта Car:
```
1. В программе пишем: 
   Car car = new Car("Toyota", "Camry", 2022, 2900000, 4, "седан")

2. Вызывается конструктор Car с параметрами:
   - make = "Toyota"
   - model = "Camry"  
   - year = 2022
   - price = 2900000
   - numDoors = 4
   - bodyStyle = "седан"

3. Конструктор Car вызывает base(make, model, year, price)
   - Передаёт "Toyota", "Camry", 2022, 2900000 в конструктор Vehicle

4. Выполняется конструктор Vehicle:
   - Make = "Toyota"
   - Model = "Camry"
   - Year = 2022
   - Price = 2900000

5. Возвращаемся в конструктор Car:
   - NumDoors = 4
   - BodyStyle = "седан"

6. Объект полностью создан!
```

Порядок выполнения конструкторов:
```
1. Конструктор Car
   ↓
2. Конструктор Vehicle (через base)
   ↓
3. Конструктор Object (неявно, для Vehicle)
   ↓
4. Тело конструктора Vehicle
   ↓
5. Тело конструктора Car
```
